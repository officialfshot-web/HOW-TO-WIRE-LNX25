# LN-25X Field Guide

Interactive guide to the Lincoln LN-25X wire feeder: parts, a hands-on wire loading simulation, 2-step/4-step trigger modes, a settings simulator, a heat chart, technique, and troubleshooting.

It's a single static page (`index.html`) with no build step. To deploy on Vercel, import this repo and keep the default settings.

Settings shown are teaching starting points. Always go by the spool label, your WPS, and a test bead on scrap.
